# Flashcards - Encryption, KMS, and Secrets Management

1. Service for automatic secret rotation?
- Secrets Manager.

2. Lower-cost app parameters?
- Parameter Store.

3. Key with full customer control?
- Customer-managed KMS key.

4. Which policy is mandatory in KMS?
- Key policy.

5. Which pattern does encryption at scale use?
- Envelope encryption.

6. In which region must the CloudFront certificate in ACM be?
- us-east-1.

7. Best practice for an app to access a secret?
- IAM role, no hardcoded credential.

8. Service for a dedicated HSM?
- AWS CloudHSM.

9. Auditing key usage?
- CloudTrail.

10. When to use Secrets Manager on the exam?
- When there is a requirement for automatic rotation.
